**`pricebrush.pages.dev` looks free today:** DNS through 1.1.1.1 returns "Non-existent domain". That doesn't guarantee the name can be claimed. F1 says what to do if it can't.

**Pages or Workers?** Cloudflare's Pages docs now say ["Start new projects with Workers."](https://developers.cloudflare.com/pages/) Pages is not marked deprecated. **I recommend staying on Pages for 31/10.** The PRD, `SITE_URL`, every SEO doc and the listings plan assume `pricebrush.pages.dev`. `_headers`/`_redirects` behave as tested above, and moving to Workers static assets later is a small change we can make together with the domain move. **Strongest argument against:** Cloudflare puts new features into Workers, so we may move once anyway. **What would change my mind:** a Pages deprecation date, or a Pages feature we need that's missing.
