## YouTube video script: written around Sun 15/11, not now

> **Untuk Arif:** Skrip video (klik demi klik, plus teks di layar) baru ditulis sekitar **Minggu 15/11**, setelah tampilan aplikasi yang asli ada. Kalau ditulis sekarang, skripnya pasti salah karena UI app belum jadi. Kamu rekam 18–19/11, upload sebagai "Scheduled" untuk Rabu 25/11.

What the script will cover (decided now, so nothing is lost):
- **Length and format:** one landscape screen recording, 2–3 minutes, on-screen text only (no face, no voice needed). Optional: a vertical crop of the same clip as a Short, only if it takes ≤ 10 minutes.
- **Tools:** Xbox Game Bar (`Win + Alt + R`) or OBS to record; Clipchamp to cut and add text.
- **Story:** room sizes in the free calculator → litres, tins, days and a price at the decorator's day rate → "Turn this into a quote" → a quote sent as a WhatsApp link. Only features that work on the day of recording.
- **Address:** `pricebrush.co.uk` as on-screen text for the whole video and as plain text in the description. Links aren't clickable on a new channel without advanced features, and the founder chose no ID verification ([YouTube Help](https://support.google.com/youtube/answer/9890437?hl=en-GB)). If the lead builds the proposed `/video` short path, show `pricebrush.co.uk/video` instead, so visits can be counted.
- **Numbers:** taken from the live calculator on the day, never typed by hand. The defaults are 12 m²/L, 40 m² a day, £6/L and £200 a day.
- **Claims:** the same rules as everything else: no "60 seconds", "in minutes", "AI-powered", "cheapest", ratings or user counts; "5 quotes or invoices **a month**"; no Founding offer in the video.
